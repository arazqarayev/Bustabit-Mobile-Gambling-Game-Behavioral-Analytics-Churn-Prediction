# Bustabit-Mobile-Gambling-Game-Behavioral-Analytics-Churn-Prediction
This project focuses on user behavioral analysis and churn prediction using real transactional data from an online gaming platform (Bustabit).
1)I used it 'https://www.kaggle.com/datasets/kingabzpro/gambling-behavior-bustabit/data'


# 🧠 Bustabit Davranışsal Analiz ve Churn Tahmin Projesi

## 📊 Proje Özeti

Bu proje, Bustabit platformuna ait **gerçek işlem verileri** kullanılarak gerçekleştirilen **uçtan uca davranış analizi ve churn (müşteri kaybı) tahmin çalışmasıdır**.

Amaç; kullanıcıların platform üzerindeki davranışlarını anlamak, sadık kullanıcıları ayırt etmek, terk etme riski bulunan kitleyi tespit etmek, zaman bazlı aktivite kalıplarını analiz etmek ve **makine öğrenmesi modeli ile churn tahmini yapmaktır**.

---

## 🎯 Proje Hedefleri

- **RFM Analizi (Recency – Frequency – Monetary)** ile kullanıcı segmentasyonu yapmak
- Kullanıcıları şu segmentlere ayırmak:
  - **Power User (Sadık & yüksek değerli kullanıcı)**
  - **Normal User**
  - **Churn Risk (Terk riski taşıyan kullanıcı)**
- Platformdaki **aktivite davranışlarını** incelemek:
  - Hangi saatlerde yoğunluk artıyor?
  - Haftanın hangi günleri kullanıcı sayısı yükseliyor?
  - Zamanla kullanım eğrisi nasıl değişiyor?
